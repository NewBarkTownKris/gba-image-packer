# Credits

GBA Image Packer includes a Rust desktop application and ARM7TDMI cartridge firmware.

- The desktop UI uses Noto Sans Regular, under the Apache License 2.0. See `assets/Noto-LICENSE.txt`.
- The cartridge bitmap font was rasterized from DejaVu Sans Mono. See `assets/DejaVu-LICENSE.txt`.
- The application uses macroquad, image, serde, serde_json, and tinyfiledialogs, together with their dependencies. Release packages include dependency names, license expressions and license texts in `licenses/`.
- mGBA is used by the optional development test harness. It is not linked into the desktop app or cartridge.
- Procedural sample landscapes used by screenshot and self-test modes are generated by the application.
